## 💻 Projeto

O **Frequência+** é um sistema web criado para facilitar o controle e o gerenciamento da frequência dos alunos. A plataforma foi desenvolvida para tornar esse processo mais simples, organizado e eficiente, substituindo registros manuais por uma solução digital.

Entre suas principais funcionalidades estão o cadastro e gerenciamento de alunos, registro de frequência, consulta e acompanhamento da presença, organização das informações acadêmicas e visualização dos dados de forma prática. O sistema também busca facilitar o acesso às informações e auxiliar no acompanhamento da frequência dos estudantes.

Com uma interface intuitiva e foco na praticidade, o Frequência+ contribui para otimizar a rotina de professores e responsáveis pela gestão escolar, reduzindo processos manuais e tornando o gerenciamento da frequência mais rápido, organizado e confiável.

## 🔧 Principais funcionalidades:
  - 👨‍🎓 Cadastro de alunos — registro e organização das informações dos estudantes.
  - 📋 Registro de frequência — controle digital da presença e ausência dos alunos.
  - 🔎 Consulta de frequência — acompanhamento do histórico de presença de forma rápida.
  - 📊 Acompanhamento dos dados — visualização das informações de frequência de maneira organizada.
  - 🗂️ Gerenciamento de informações — centralização e organização dos dados dos alunos.
  - ⚡ Interface prática e intuitiva — navegação simples para facilitar o uso no dia a dia.
  - 💻 Acesso via Web — utilização do sistema de forma prática por meio do navegador.
  - 📈 Apoio à gestão escolar — facilita o acompanhamento da frequência e contribui para uma gestão mais eficiente.

## 🎯 Objetivo:
O objetivo do Frequência+ é desenvolver uma solução web que facilite o controle e o acompanhamento da frequência dos alunos, tornando esse processo mais simples, rápido e organizado. O projeto busca reduzir a utilização de registros manuais, melhorar a organização das informações e facilitar o acesso aos dados de presença, contribuindo para uma gestão escolar mais eficiente e prática.

## 💡 Tecnologias utilizadas:
  - HTML5 — utilizado para estruturar as páginas e os elementos do sistema.
  - CSS3 — responsável pela estilização, organização visual e responsividade da interface.
  - JavaScript — utilizado para implementar funcionalidades e interações do sistema.
  - Banco de Dados — utilizado para armazenar e organizar as informações dos alunos e seus registros de frequência.
  - Git e GitHub — utilizados para versionamento, organização e compartilhamento do código-fonte do projeto.
  - Visual Studio Code — utilizado como ambiente de desenvolvimento para criação e edição dos arquivos do sistema.
